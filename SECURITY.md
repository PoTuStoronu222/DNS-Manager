# Политика безопасности

## Поддерживаемые версии

Исправления безопасности публикуются в актуальной версии DNS Manager из ветки `main`. Перед сообщением об ошибке проверьте, воспроизводится ли она в актуальной версии.

## Как сообщить об уязвимости

1. Откройте [страницу Security проекта](https://github.com/PoTuStoronu222/DNS-Manager/security).
2. В разделе **Security advisories** нажмите **Report a vulnerability**.
3. Опишите проблему, шаги воспроизведения, возможное влияние и версии OpenWrt и DNS Manager. При необходимости приложите обезличенные журналы.

Сообщение будет доступно сопровождающим проекта в приватном обсуждении. Не размещайте подробности уязвимости, пароли, ключи, токены и личные данные в публичных Issues. Не проводите проверки на чужих устройствах без разрешения владельца.

После получения сообщения сопровождающий изучит его и свяжется с вами через GitHub. Публичное раскрытие и исправление обсуждаются в приватном отчёте.
